01 · What you get

One active-length model, four matrix views

The calculation builds a signed branch inductance matrix from the generated slot/layer conductors, then derives a phase matrix assuming equal current in parallel branches. Values are partial inductances for the straight active stack section; they are not a complete terminal-to-terminal machine inductance.

Branch matrix · μH

Self and mutual terms for each winding branch, with signed branch current references.

Phase matrix · μH

Branch matrix reduced to phase ports under equal parallel-branch current sharing.

Normalized · k

Signed coupling ratios, kᵢⱼ = Lᵢⱼ / √(LᵢᵢLⱼⱼ); each diagonal is exactly 1.

02 · Geometry & reference directions

Conductor centres set mutual spacing; the sign map sets polarity

How winding geometry enters

For slot index s and layer radius r, each conductor centre is placed at θ = 2πs / Nslots and (x,y) = (r cos θ, r sin θ). Pairwise Euclidean distance supplies the mutual spacing dᵢⱼ.

The independent phase-topology map supplies each conductor's phase and signed direction. Series-connected conductor contributions are added with those signs. A negative mutual entry means opposing linkage under the displayed positive-current references.

A branch must have balanced positive and negative active sides. This is a model admission check; it does not certify strong symmetry, equal induced EMF, or manufacturing suitability.

04 · Equations

Rectangular self GMR → finite-segment kernel → matrices

The self GMR is derived directly from the current conductor width w and height h. Set a = min(w,h), b = max(w,h), r = a/b; the exact geometric-mean distance of a uniformly filled rectangle is:

rGMR = b exp[ ½ln(1+r²) − (r²/12)ln((1+r²)/r²) − ln(1+r²)/(12r²) + (2r/3)atan(1/r) + 2atan(r)/(3r) − 25/12 ]This dimension-dependent expression is symmetric in width and height. The commonly used 0.2235(w+h) is a close approximation, not a user input in this tab.

For two aligned finite straight segments of equal active length ℓ and transverse separation d, the geometric partial-inductance kernel used in the model is:

P(d,ℓ) = (μ₀ μᵣ / 2π) [ ℓ asinh(ℓ / d) − √(ℓ² + d²) + d ]Mutual terms use d = centre-to-centre distance. Self terms use d = rGMR. Here μ₀ = 4π × 10⁻⁷ H/m.

Let P be the conductor-level matrix with entries Pᵢⱼ = P(dᵢⱼ,ℓ). Let S be the signed conductor-to-branch incidence matrix: each row assigns one conductor to a branch with its +1 or −1 phase-map direction. Then the branch matrix is:

Lbranch = Sᵀ P S

For phase p with np parallel branches, the equal-sharing matrix C assigns 1/np from each branch to that phase. Phase port currents are distributed equally, so:

Lphase = Cᵀ Lbranch C

For either reported matrix, the normalized signed coupling is:

kᵢⱼ = Lᵢⱼ / √(Lᵢᵢ Lⱼⱼ),   kᵢᵢ = 1

The geometric-mean denominator preserves symmetry when self-inductances differ. The sign of kᵢⱼ follows the same reference-current convention as the inductance matrix.

05 · Using the tab

Calculate, inspect, then recalculate after physical changes

  1. Generate or configure the current layout. The calculation uses the current layout's conductors, branches, stack length and layer radii.
  2. Set μᵣ if needed. The rectangular GMR is calculated automatically from the current conductor width and height; its value appears in the read-only field after calculation.
  3. Select Calculate Inductance. The summary reports model values and the four tabs show phase/branch matrices in μH and normalized k.
  4. Read matrix labels and signs. Phase labels identify phases; branch display labels are phase-local (for example A-B1). Negative values reflect the sign-map port references, not a calculation error by themselves.
  5. Use Pop Out Matrix for inspection. It moves the selected existing matrix table to a resizable window. Use Embed Matrix or close that window to return the table.
Results go stale after model or physical inputs change. The displayed matrices are cleared; calculate again before relying on them. Figure-only display changes do not alter this physical result.

06 · Assumptions & limits

Use this as a bounded analytical estimate

  • Each conductor is a finite, straight, parallel segment spanning the active stack length.
  • The magnetic medium is homogeneous and represented by one scalar μᵣ.
  • The self-GMR uses the exact rectangular-area GMD, assuming uniform current density over the cross-section.
  • Phase matrices assume equal current sharing among parallel branches in each phase.
  • Current directions follow the phase-topology reference; end turns and their mutual coupling are omitted.
  • Slot/tooth iron boundaries, nonlinear saturation, rotor/stator material distribution and skew are omitted.
  • Frequency-dependent skin and proximity current redistribution is omitted.
  • There is no FEM field solve or terminal-path closure; matrices alone do not validate the generated winding.

A candidate layout can still produce a matrix for inspection. Calculation success is not winding symmetry certification, manufacturing approval, or a full machine parameter prediction.
