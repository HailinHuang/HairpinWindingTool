Read the diagrams

Columns = slots; rows = layers. All diagrams use slots 1, 2, 7, 8, 13, 14, 19, 20 with the same spacing and scale. Wider gaps separate the pole regions; other slots are omitted.

Follow the numbered circles. Each circle is a conductor; its number gives the connection order. Paths leaving a side edge continue at the opposite edge. Line crossings are not joints.

Solid teal: insertion-side pins.
Dashed slate: weld-side connections.
Amber: the key connection to compare.

SL = same-layer return; TB = top–bottom return in the spiral/lap comparison. An SL Pattern still traverses multiple layers.

Generated examples: 24 slots · 4 poles · 3 phases · 4 layers · q = 2 · Naa = 2. These branch diagrams explain connections; electrical balance depends on the complete layout and transposition.

Structural checks below apply to these unshifted base variants. L = layer count; τ = slots/poles. Use signed slot steps across the circumference seam, not left/right screen direction. A pass excludes its return. These checks are necessary, not complete acceptance rules; other divider, transposition and terminal variants need their own checks.

Ten connection patterns

Advantages and limitations are qualitative and depend on the full layout. Click a figure to enlarge it.

BWPBi-directional Wave

Adjacent-layer waves travel around the stator, then return in the opposite direction.

Check: Ordinary edges change one layer. The same-layer return separates forward and backward runs.

Advantage
Repeated adjacent-layer wave pins give a regular main path.
Limitation
Return pins add variety; weld-side terminals can require extra pin types.

UWPUni-directional Wave

The wave keeps advancing in one circumferential direction, moving between layer pairs.

Check: Every edge changes one layer; all signed slot steps have the same direction.

Advantage
Consistent circumferential progression gives a regular winding sequence.
Limitation
Long- or short-pitch transitions and branch balancing need attention.

SSPSL Spiral

A spiral steps through the layers, then uses same-layer boundary returns.

Check: Within a pass, layer steps are all +1 or all −1 and slot direction stays constant. Boundary returns stay in one layer.

Advantage
Reuses adjacent-layer pins; boundary returns offer terminal-routing flexibility.
Limitation
Local return and transposition regions need space and pitch checks.

TSPTB Spiral

A spiral steps through adjacent layers, then returns from the last layer to the first.

Check: Within a pass, layer steps are all +1 or all −1 and slot direction stays constant. Each return spans L−1 layers.

Advantage
Top–bottom returns can reduce the number of distinct pin shapes.
Limitation
The large layer span makes forming and end-winding clearance more demanding.

SLPSL Lap

Lap connections alternate circumferential direction while stepping through the layers.

Check: Within a pass, layer steps are all +1 or all −1 while slot direction alternates. Boundary returns stay in one layer.

Advantage
Boundary returns can accommodate a terminal-side change without new pin types.
Limitation
Return paths and local transposition still need end-space checks.

TLPTB Lap

Lap connections step through adjacent layers; a top–bottom link starts the next pass.

Check: Lap passes alternate slot direction; returns span L−1 layers. An even-layer, full-pitch pass has net slot displacement ±τ.

Advantage
Provides a direct top–bottom return for the lap sequence.
Limitation
Cross-layer pins add forming and clearance demands.

ZLPZ Lap

Short-pitch lap steps make a zigzag within a layer pair before moving to the next pair.

Check: Inside a layer pair, lap pins reverse the preceding weld direction. Check pair-changing edges and same-layer returns separately.

Advantage
Repeated pitch offsets provide progressive phasor transposition.
Limitation
Pitch variation adds pin shapes; terminal-side choices can be restrictive.

ZPPZ Parallel

Same-layer pins advance in one direction; weld connections move between layers.

Check: Every insertion pin stays in one layer and advances in the same slot direction; every weld changes one layer.

Advantage
Keeps the two legs of each main pin in the same layer.
Limitation
Many layer-specific pin shapes; V7.6 requires weld-side inlets.

CPCross-Layer

Cross-layer insertion pins alternate with adjacent-layer weld connections.

Check: In this even-layer variant, every insertion pin spans L/2 layers; every weld spans one layer.

Advantage
Can cover the layer groups with relatively few distinct pin shapes.
Limitation
Larger radial spans can increase bending height and forming difficulty.

LPPLoop Parallel

Same-layer pins run in opposite directions in paired layers, creating repeated loops.

Check: Every insertion pin stays in one layer. Pin directions are opposite in the two layers of each pair; welds change one layer.

Advantage
Organizes the branch into repeated loops within layer pairs.
Limitation
Different loop spans add pin variety; V7.6 requires weld-side inlets.

Use it in the software

  1. Set the windingEnter slots, poles, layers and parallel branches. Choose an enabled Pattern; read the reason for any disabled choice.
  2. Set the connectionsChoose branch dividers, terminal side and transposition. ZPP and LPP require weld-side inlets in V7.6.
  3. Generate and checkRun Layout Analyze or Plot Layout. Inspect coverage, phase/direction, parallel EMF and edge checks, then review end space and busbars.

A plotted candidate is not a validated winding. Check the analysis status, especially strong symmetry, before using the layout.
