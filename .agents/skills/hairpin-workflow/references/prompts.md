# Optional prompts

Natural language is enough. Add details only when useful:

> Goal: ...; Current behavior: ...; Expected result: ...; Constraints: ...; Reference config or screenshot: ...

- "Reduce spacing between Figure controls; preserve behavior."
- "Add a detachable winding-factor chart that retains its data when redocked."
- "The adjacent-slot summary misses the last-to-first slot pair. Reproduce and fix it."
- "Explain why fractional q is rejected; do not expand support."
- "Investigate this fractional-q winding; keep candidates separate until electrical checks pass."
- "Refactor duplicate export setup while preserving the saved format."
- "Prepare V7.5 and verify config import, layout and VD export."

An explicit mode is optional: "Mode: debug. Here is the failing config..." Actual impact still determines risk. For ambiguous "layout", distinguish window arrangement, rendered geometry and electrical connections.
